# giesela Smart Plant Watering Assistant

automated plant watering, against my not so green thumb

> **Giesela** monitors the soil moisture levels of your plants and alerts you (or waters them automatically) as soon as the soil gets too dry.

---

## 💡 Features

* **Custom Thresholds:** Tailored moisture settings for different plant types (e.g., Monstera,Fern, efeutute).
* **Sensor Monitoring:** Regular checks of soil moisture levels in percentage.
* **Smart Alerts:** Clear automated notifications whenever a plant needs attention.

---

## 🛠️ Tech Stack

* **Language:** Python 3.10+
* **Data Format:** JSON (Configuration & plant data)
* **Tools:** Git, GitHub
